# Commander preferences

Durable preferences the XO must honor. The XO records each lasting preference the commander
states as a ruling: `chartroom rule add --topic <slug> "<text>"` appends it to `rulings.log`,
where the newest ruling in a topic wins, and rewrites the generated block below. Never edit
the block by hand; text outside it is hand-written.

- Delivery default: commit on a task branch in an isolated worktree; never push, open a PR, or merge without my word in the moment.
- Escalate only decisions I must make. Batch status; never report "still working".
- Backend default: pick per the chartroom skill's rubric unless I name one.
